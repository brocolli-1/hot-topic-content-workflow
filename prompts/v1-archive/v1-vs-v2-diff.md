# v1 → v2 迭代说明

> **作者**:brocolli
> **迭代时间**:2026-09-06  
> **对比对象**:v1.0 (2026-08 初版) vs v2.0 (2026-09-06 改写版)

本文件说明 v1 → v2 改了什么、为什么改

## 1. 整体改动概览

| 维度 | v1.0 | v2.0 |
|---|---|---|
| 元信息(版本号/日期) | ❌ 无 | ✅ 每段开头标注 |
| 角色边界(禁忌) | ❌ 无 | ✅ 5 类边界 |
| 反面例子 | ❌ 无 | ✅ 18 条 |
| 输入格式约束 | ❌ 无 | ✅ 提示词 1/4 明确 |
| 评分方法 | ⚠️ 只给分值含义 | ✅ 公式化(相关度×0.5 + 匹配度×0.3 + 时效性×0.2) |
| 兜底逻辑(低关联度/数据不足) | ❌ 无 | ✅ 提示词 2/4 明确 |
| 上期策略回看 | ❌ 无 | ✅ 提示词 4 新增 |
| 自动化兼容性 | ⚠️ 提示词 3 卡在追问 | ✅ 完整输入模式 + 追问模式 双模式 |

## 2. 逐段改动对照

### 提示词 1:热点检索

| 项 | v1 | v2 |
|---|---|---|
| 输入说明 | 隐含在任务里 | 单独 ## 输入 段 |
| 检索范围 | 写死 14 天 | 参数化 `{{days}}` |
| 评分标准 | 只有分值含义 | 含义 + 公式 |
| 数据来源 | 表格无来源列 | 增加「数据来源」列 |
| 兜底 | 1-3 分"放弃" | 加反问:无可关联商品时输出"本周无强匹配" |

### 提示词 2:选题策划

| 项 | v1 | v2 |
|---|---|---|
| 脚本结构 | 画面+台词写一起 | 三列表格:画面/台词/字幕 |
| 央企调性 | 笼统说"不能太夸张" | 加反面例子:不要"传承经典,匠心之作",要"1973 年首版印刷只有 5000 张" |
| 兜底 | 缺字段会自由发挥 | 字段缺失先反问,禁止编造 |
| 关联度兜底 | 无 | 关联度<4 时输出"建议暂缓",不硬出选题 |

### 提示词 3:封面提示词

| 项 | v1 | v2 |
|---|---|---|
| 工作模式 | 单模式(必须追问) | 双模式:完整输入 / 追问 |
| 自动化场景 | ❌ 卡在追问 | ✅ 完整输入模式可直接跑批 |
| 尺寸参数 | 硬编码 1080×1440 | 参数化 3:4 |
| 文字示例 | 仅英文杂志示例 | 增加中文封面示例 |
| 反面例子 | 无 | 4 条 |

### 提示词 4:数据复盘

| 项 | v1 | v2 |
|---|---|---|
| 输入格式 | 自由 | 明确字段:发布日期/标题/形式/曝光/点赞/收藏/评论/商品点击 |
| 数据量门槛 | 无 | ≥14 条,否则输出"数据不足" |
| 上期回看 | 无 | 必填 {{done_tests}} / {{pending_tests}} |
| A/B 成功判定 | 笼统"提升 X%" | 每条假设必填「成功判定」指标 |
| 风险提示 | 1 条笼统 | 模板化,至少 1 条具体风险 |

## 3. v1 仍保留的价值

虽然 v2 更完善,但 v1 仍有 3 个值得保留的理由:

1. **叙事素材**:"v1 我犯过 X 错 → v2 改成 Y → 实测效果 Z" 是非常强的故事
2. **回归测试用**:如果 v3 改完发现 v2 反而更差,能快速回滚比对
3. **方法论沉淀**:v1 体现的是"初学者直觉",v2 体现的是"工程化思维",两者都是成长记录

## 4. 后续 v3 计划(预留)

待 v2 在业务中跑 1-2 周后,根据真实痛点迭代 v3。可能的优化方向:
- 接入真实 API(替换手动跑)
- 提示词 1 增加"长尾词挖掘"维度
- 提示词 4 增加"竞品对标"模块
- 整套接入 GitHub Actions 定时跑
