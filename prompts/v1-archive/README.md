## 归档约定

1. **冻结原则**:归档文件不再修改,如有勘误请开 v2
2. **命名规则**:`NN-{slug}-v{N}.md`,N 为提示词编号,v{N} 为版本号
3. **新版本归档**:每次 v(N+1) 发布时,把 `prompts/` 根目录的当前文件复制到本目录,文件后缀加 `-v{N}`
4. **配套文档**:每次归档时,在 `v1-vs-v2-diff.md`(或 `v{N}-vs-v{N+1}-diff.md`)中记录改动说明
