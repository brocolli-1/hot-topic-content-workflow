# 工作流流程图

> 流程图源文件见 `assets/flow.svg`(待补充),下面是文字版说明。

## 流程示意

```
                ┌─────────────────────┐
                │  ① 热点检索 Agent   │
                │  输入:商品列表+范围  │
                │  输出:7日排期表     │
                └──────────┬──────────┘
                           ↓
                ┌─────────────────────┐
                │  ② 选题策划 Agent   │
                │  输入:热点+商品+卖点│
                │  输出:3 选题+脚本   │
                └──────────┬──────────┘
                           ↓
                ┌─────────────────────┐
                │  ③ 封面提示词 Agent │
                │  输入:标题+卖点+主体│
                │  输出:AI 绘图提示词 │
                └──────────┬──────────┘
                           ↓
                ┌─────────────────────┐
                │  ④ 数据复盘 Agent   │
                │  输入:14 天数据     │
                │  输出:下周策略+A/B │
                └──────────┬──────────┘
                           ↓
                  (反馈回 ① 排期)
```

## 节点说明

| 节点 | 工具 | 触发 | 频率 |
|---|---|---|---|
| ① 热点检索 | GPT-5.6 / Gemini | 每周一上午 | 1 次/周 |
| ② 选题策划 | GPT-5.6 | 每条内容开始前 | 3-5 次/周 |
| ③ 封面提示词 | GPT-5.6 + GPT image-2 | 每条内容开始前 | 3-5 次/周 |
| ④ 数据复盘 | GPT-5.6 | 每周一上午 | 1 次/周 |

## 人机分工

| 环节 | AI 负责 | 人负责 |
|---|---|---|
| ① 检索 | 跨平台抓取、关联度评分、排期生成 | 最终选题判断、优先级调整 |
| ② 选题 | 文案生成、3 个备选、标签 | 选 1 个微调、情绪锚点校准 |
| ③ 封面 | 提示词生成、A/B 备选 | 主体选择、色彩微调 |
| ④ 复盘 | 数据归因、规律提炼、假设生成 | 业务解读、动作优先级、负责人分配 |
