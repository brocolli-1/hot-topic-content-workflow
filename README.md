# 短视频内容生产 AI 工作流(4 段提示词 v2)

> **适用场景**:CD / 黑胶唱片 · 音乐类内容
> **目标平台**:小红书(图文 / 竖屏视频)
> **核心工具**:GPT-5.6 / Gemini / GPT image-2 / 剪映
> **当前版本**:v2.0 · 2026-09-06
> **License**:MIT

---

## 一、为什么做这个

我在做内容运营时,发现"找热点 → 选选题 → 写文案 → 看数据"这套动作每周要重复很多次。
于是把这四步拆成可复用的提示词流程,做到:

- **检索环节**:AI 跑第一遍,人做最终判断
- **生成环节**:AI 出 3 个备选,人挑 1 个微调
- **复盘环节**:AI 做数据归因,人做业务解读

> **工作流的设计目标不是全自动化,而是人机协作的最优效率比。**
> 核心理念:AI 负责检索、生成、统计;人负责判断、筛选、审美。

---

## 二、流程长什么样

```
[热点检索 Agent]   →  7 日排期表
        ↓
[选题策划 Agent]   →  3 个选题备选 + 完整脚本
        ↓
[封面提示词 Agent] →  AI 绘图正向 / 负向提示词
        ↓
[数据复盘 Agent]   →  下周期策略 + A/B 测试
        ↓ (反馈回 ①)
```

## 四、四段提示词分别做什么

| # | 提示词 | 输入 | 输出 | 触发频率 |
|---|---|---|---|---|
| 1 | 热点检索 | 商品列表 + 检索范围 | 7 日排期表 | 每周一次 |
| 2 | 选题策划 | 热点 + 商品 + 卖点 + 情绪锚点 | 3 个标题 + 脚本 + 标签 | 每条内容 1 次 |
| 3 | 封面提示词 | 标题 + 卖点 + 主体元素 | AI 绘图提示词 | 每条内容 1 次 |
| 4 | 数据复盘 | 14 天数据 + 上期策略 | 下周策略 + A/B | 每周一 |

## 五、迭代关键节点

| 版本 | 改动 | 效果 |
|---|---|---|
| v1.0 | 初版,只有角色和任务 | 跑通但输出飘 |
| v1.2 | 加约束、反面例子 | 稳定性提升 |
| v2.0 | 加输入格式、边界、数据门槛 | 兼容自动化 |

---

## 六、学到的 3 件事

1. 提示词里加"反面例子"比加"正面规则"更管用
2. 缺输入格式等于让 AI 自由发挥
3. 数据复盘必须卡样本量门槛(< 14 条不归因)

---

## 七、局限

- 4 段手动串联,未接自动化工具
- 数据复盘未接 API,需手动导出
- 未做过多 LLM 横评
